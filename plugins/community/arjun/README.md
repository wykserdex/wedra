# arjun

Фаззинг скрытых GET-параметров по словарю из 25 890 имён (s0md3v/Arjun), обёртка над CLI.
Работает только по одной цели, которую задал оператор: `-u <url>` + `-oJ <report.json>` (у arjun есть только `-o`/`-oJ`, длинной формы `--output-json` нет).

Установка внешнего инструмента: `pip install arjun` (точка входа — консольный скрипт `arjun`; работает и `python -m arjun`).
Путь к бинарю переопределяется env `ARJUN_BIN`.
