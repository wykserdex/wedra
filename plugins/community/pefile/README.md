# pefile

Разбор PE-файла (erocarrera/pefile): архитектура (`IMAGE_FILE_MACHINE_*`), секции
и импортируемые DLL с символами. У pefile нет CLI — плагин запускает тот же
интерпретатор с фиксированным сниппетом (`python -c …`), который импортирует
библиотеку и печатает JSON.

Установка внешнего инструмента: `pip install pefile`.
Путь к донору переопределяется env `PEFILE_BIN`.
