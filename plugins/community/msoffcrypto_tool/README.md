# msoffcrypto_tool

Расшифровка офисных документов, защищённых паролем (nolze/msoffcrypto-tool).
Пароль берётся только из env `MSOFFCRYPTO_PASSWORD` — во входе его нет и в отчёт
он не попадает. Если `out` не задан, расшифрованный файл кладётся во свежий
временный каталог ОС, и его путь возвращается в `output_path` (каталог намеренно
не убирается — иначе путь был бы мёртвым). Без переменной с паролем плагин
работает в режиме проверки `-t -v`: `decrypted=false`, `output_path` пустой.

Установка внешнего инструмента: `pip install msoffcrypto-tool`.
Путь к бинарю переопределяется env `MSOFFCRYPTO_TOOL_BIN`.
