# buckethacker

Поиск открытых облачных хранилищ (S3/Azure Blob/GCS/Spaces) по имени бакета или
storage-аккаунта. Обёртка над CLI `buckethacker`, отчёт читается из stdout.

Установка внешнего инструмента: `pip install buckethacker`.
Путь к бинарю переопределяется env `BUCKETHACKER_BIN`.

ДОНОР НЕ ПОДТВЕРЖДЁН: репозиторий `ingo60/buckethacker` на GitHub не существует
(поиск по имени — 0 репозиториев), пакет на PyPI не подтверждён. CLI собран
консервативно — только позиционный аргумент `<name>`, без флагов; отчёт
читается как JSON, а при его отсутствии разбирается текст (эвристика по
маркерам). Ключи не нужны: поиск анонимный.
