# dnsrecon

DNS-разведка домена (A/NS/MX/SOA/SPF/CNAME/AXFR, опционально брутфорс
поддоменов по словарю) — обёртка над CLI dnsrecon, читает JSON-репорт `-j`
(имя файла, не булев флаг).

Допустимые `types` — ровно те, что принимает `-t/--type` у донора: `std`,
`rvl`, `brt`, `srv`, `axfr`, `bing`, `yand`, `crt`, `snoop`, `tld`,
`zonewalk`. Типа `spf` среди них нет — обратный резолв диапазонов из SPF-текста
включается отдельным булевым флагом `-s`, который обёртка не передаёт.

Установка внешнего инструмента: `pip install dnsrecon`.
Путь к бинарю переопределяется env `DNSRECON_BIN` (по умолчанию `python3 -m dnsrecon`).
