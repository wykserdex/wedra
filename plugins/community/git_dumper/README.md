# git_dumper

Поиск и выкачивание оставленного `.git` на целевом хосте (arthaud/git-dumper).
Отдаёт стадии обхода, пробу `.git/HEAD` и список скачанных файлов; сам дамп
складывается во временный каталог ОС и наружу не отдаётся.

Установка внешнего инструмента: `pip install git-dumper` (CLI-скрипт `git-dumper`).
Путь к бинарю переопределяется env `GIT_DUMPER_BIN`.
Плагин предназначен для целей, которые вы проверяете сами или на которые есть
письменное разрешение.
