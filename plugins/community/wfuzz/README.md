# wfuzz

Фаззинг URL, путей и параметров по словарю (de4nsid4n/wfuzz), обёртка над CLI wfuzz.
Цель (`url`) и словарь (`wordlist`) задаёт пользователь; маркер `FUZZ` остаётся в URL
и подставляется донором. На выходе — ответы, прошедшие фильтр (`matcher` → `--filter`).

Установка внешнего инструмента: `pip install wfuzz` (дальше доступен `python3 -m wfuzz`).
Путь к бинарю переопределяется env `WFUZZ_BIN`.

В каталоге плагина лежит `wordlist.txt` — минимальный пример словаря; относительный
путь `wordlist` во входе отсчитывается от каталога плагина. Пустой `wordlist` — ошибка:
у pip-пакета wfuzz своего дефолтного словаря нет.
