# gospider

Краулер с извлечением эндпоинтов из JavaScript (jaeles-project/gospider), обёртка над CLI.
Отчёт gospider (`-o` + `--json`) разбирается в плоский список url / javascript / linkfinder / form / subdomain.

Установка внешнего инструмента: `go install github.com/jaeles-project/gospider@latest`.
Путь к бинарю переопределяется env `GOSPIDER_BIN`.
