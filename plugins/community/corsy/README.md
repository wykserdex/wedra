# corsy

Поиск CORS-мисконфигураций по одной явно заданной цели (s0md3v/Corsy),
обёртка над CLI. Только неинвазивные GET-пробы с заголовком `Origin`: цели не
меняются, данные не извлекаются. Разведки домена нет — сканируется ровно тот
url, что задан во входе (`-i` у Corsy — это файл со списком url, а не цель).

Свой список `Origin` задать нельзя: Corsy v1.0-beta проверяет свой
фиксированный набор. Поле `origins` только валидируется, а в finding попадает
тот Origin, который сервер реально отразил в `Access-Control-Allow-Origin`.

Установка внешнего инструмента: `git clone https://github.com/s0md3v/Corsy &&
pip install -r requirements.txt` (на PyPI пакета `corsy` нет).
Путь к `corsy.py` переопределяется env `CORSY_BIN`.
