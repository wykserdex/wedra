# spiderfoot

OSINT-скан цели через SpiderFoot (smicallef/spiderfoot), 200+ модулей. Неинтерактивный вызов
`spiderfoot -s <цель> -o json -q [-m <модули>]`, результат читается из stdout.

Установка внешнего инструмента: `pip install spiderfoot` либо распакованный релиз v4.0
(`python3 ./sf.py -l 127.0.0.1:5001`). Путь к бинарю (`spiderfoot`, `sf.py` или свой)
переопределяется env `SPIDERFOOT_BIN`.

Два момента, о которых надо знать:

- Поле `module` лучше всегда задавать. Без него `sf.py` включает **все** установленные
  модули — скан будет очень долгим.
- SpiderFoot сам пишет свою БД сканов в `~/.spiderfoot/spiderfoot.db` (вне рабочего
  каталога плагина), поэтому в манифесте объявлен `filesystem: readwrite`.

Отчёт — JSON-массив событий, напечатанный в stdout, а не файл в рабочем каталоге.
