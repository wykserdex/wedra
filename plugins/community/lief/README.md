# lief

Универсальный разбор бинарников (LIEF-project/LIEF): PE, ELF и Mach-O одним
парсером `lief.parse`. Отдаёт формат, абстрактный заголовок (архитектура, тип
объекта, endianness, битность, entrypoint) и секции. У LIEF нет CLI — плагин
запускает тот же интерпретатор с фиксированным сниппетом (`python -c …`),
который импортирует библиотеку и печатает JSON.

Установка внешнего инструмента: `pip install lief`.
Путь к донору переопределяется env `LIEF_BIN`.
