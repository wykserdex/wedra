# detect_secrets

Поиск секретов в коде и конфигах (Yelp/detect-secrets): тип секрета, файл и номер строки.
Значения секретов и их хэши наружу не отдаются — только места находок.

Установка внешнего инструмента: `pip install detect-secrets`.
Путь к бинарю переопределяется env `DETECT_SECRETS_BIN` (по умолчанию `python3 -m detect_secrets`).
Сканирование полностью офлайн, сеть плагину не объявлена.
