# oletools

Анализ макросов офисных документов (decalage2/oletools, CLI `olevba`): какие
модули VBA/XLM нашлись, автоисполняемые вставки, подозрительные вызовы и IOCs.
Исходный код макросов в отчёт не попадает (запускаем с `-a`).

Установка внешнего инструмента: `pip install oletools`.
Путь к бинарю переопределяется env `OLETOOLS_BIN`.
Плагин для аудита собственных или явно полученных для проверки документов.
