# gallery_dl

Метаданные изображений и галерей по URL (mikf/gallery-dl), обёртка над CLI в
режиме «только метаданные»: `-j/--dump-json` печатает JSON-сообщения в stdout
(инструмент переключается на DataJob, файлы не качает), `--no-download` —
страховка от записи файлов. Плагин разбирает сообщения `Message.Url` /
`Message.Directory` и отдаёт нормализованный список позиций и заголовок галереи.

Установка внешнего инструмента: `pip install gallery-dl`.
Путь к бинарю переопределяется env `GALLERY_DL_BIN`.
