# exiftool

Чтение метаданных файла (EXIF/IPTC/XMP, модель устройства, GPS, даты съёмки) через ExifTool.

Установка внешнего инструмента — любой из двух вариантов:

1. Системный ExifTool (Phil Harvey, <https://exiftool.org>) — `exiftool.exe` на Windows,
   `sudo apt install libimage-exiftool-perl` на Linux. Это основной путь: обёртка зовёт
   `exiftool -j -q <file>` и разбирает JSON из stdout.
2. Если системного бинаря нет в PATH — `pip install pyexiftool`. Это библиотека-обёртка
   (консольного скрипта у неё нет), она сама находит перл-бинарь ExifTool, в том числе
   в каталоге установки под Windows; плагин зовёт её коротким сниппетом `python -c`.

Путь к бинарю переопределяется env `EXIFTOOL_BIN` (имя из PATH или полный путь).

Внимание: EXIF может содержать персональные данные (GPS-координаты, модель устройства,
владельца камеры) — обрабатывайте результат как чувствительные данные.
