# fierce

DNS-брутфорс домена по словарю и поиск не-непрерывного IP-пространства
(Fierce) — обёртка над CLI. У донора нет машинного вывода: обёртка
консервативно разбирает текстовый stdout (`Found: <host> (<ip>)`).

Установка внешнего инструмента: `pip install fierce3`
(оригинал haifazeem/fierce — только Python 2; бинарь ставится как `fierce3`).
Путь к бинарю переопределяется env `FIERCE_BIN` (по умолчанию `fierce3` из PATH).
