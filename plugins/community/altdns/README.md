# altdns

Генерация перестановок/мутаций субдоменов по словарю слов (altdns,
infosec-au) — обёртка над CLI altdns. Резолв не включается: плагин офлайн,
отчёт — текстовый список перестановок (дедуп + сортировка).

Установка внешнего инструмента: `pip install py-altdns`
(на PyPI «altdns» — пустая заглушка 0.0.1, не он).
Путь к бинарю переопределяется env `ALTDNS_BIN` (по умолчанию `python3 -m altdns`).
