# Посты для dev-чатов + чек-лист заливки репы

Каналы под реальные ресурсы: dev-чаты + GitHub-репа. Всё, без бюджета.
НЕ «маркетинговая кампания» — это поиск ещё 3–5 человек на грязный тест.

## Чек-лист репы (один раз, 20 минут)

1. Заменить `ВАШ_НИК_ИЛИ_ИМЯ` в `LICENSE` (MIT положен, чтобы чужие плагины было не страшно слать).
2. `git init && git add -A && git commit -m "M1–M5: оркестратор цепочек с человеком в петле + плагин-протокол v0.2"`
   (`/bin`, `/runs`, `tool` уже в .gitignore — репа чистая: исходники + плагины + доки).
3. GitHub: создать репу → `git remote add origin … && git push -u origin main`.
4. Release `v0.2-m5`: приложить `orchestrator-mvp-2026-08-28-v8.zip` — «скачал и запустил без Go».
5. В About репы: `Оркестратор конвейеров из плагинов с гейтами человека. Протокол: stdin/stdout JSON. Зелёные: 93 теста. Ищу тестеров.`

## Пост 1 — короткий (основной)

> Написал CLI-оркестратор конвейеров из плагинов с гейтами человека между шагами.
> Плагин = любой скрипт: stdin получает JSON по контракту, stdout отдаёт JSON-конверт.
> Статика ловит несовместимость шагов ДО запуска (типы/форматы/разводка портов),
> человек в узких местах смотрит, правит, принимает/отклоняет.
> Один и тот же плагин можно звать в цепочке дважды с разной разводкой (bind).
>
> Гонял трёх внешних тестеров — все трое написали свой плагин с первого захода
> (метрики текста, аудит директорий, нормализация результатов Maigret-стайл чекеров),
> ядро оценили ~9/10 для MVP. Никому не понадобился SDK — плагин это обычный скрипт.
>
> Ищу 2–3 человека на грязный тест: 15 минут до первого результата, дальше — свой
> плагин под свою задачу (по `TUTORIAL_PLUGINS.md` — он выверен на реальных граблях
> предыдущих тестеров). Репа: <ссылка>. Windows/Linux/macOS, один бинарник.
> Интересует любой фидбек — особенно где бесит.

## Правила игры в чатах (чтобы не сгореть)

- Отвечать на каждый вопрос в течение дня; каждый ответивший = потенциальный тестер.
- Сразу давать zip-ссылку, не «поставь Go и собери».
- Каждый пришедший баг → отвечать версией с фиксом в течение суток (наш цикл уже умеет).
- Не спорить про «зачем, если есть n8n/Airflow/SpiderFoot»: ответ один —
  «у них монолит исполнения, у нас контракт: ступень независимо пишется,
  тестируется и заменяется; между ступенями — человек, а не мусор на выходе».
