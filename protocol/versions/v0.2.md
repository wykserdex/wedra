# Protocol v0.2

Расширение v0.1, обратно совместимо.

Изменения:
- `bind:` в шаге пайплайна перекрывает `from` манифеста (PROTOCOL §9)
- Манифест без `from` легален: «привязку обязан дать пайплайн»
- `bind` на несуществующий порт — ошибка валидации (защита от опечаток)
- `optional: true` порт без привязки = warning, не error (фикс #10, v9)
- `file_ref` warning до запуска, если относительный путь не резолвится от cwd плагина, с подсказкой «есть от корня»
- `format` только для строк, проверяется в `plugin validate` (фикс #8, v8)
- `format_version` теперь `0.1` или `0.2`, опечатка — ошибка, не warning+OK (фикс #13, v9)
- `human_gate` коллизия basename: при коллизии ключ = `<step_id>_<basename>` (фикс #9, v9), warning в validate
- exit>=2 сохраняет конверт как `platform:<code>` для триажа (фикс #11, v9)

Обратная совместимость:
- Пайплайны `format_version: 0.1` работают без изменений
- Манифесты с `from` — дефолты, не обязательства

См. `PROTOCOL.md` §9 и `M5_FEEDBACK.md` #3-#13.
